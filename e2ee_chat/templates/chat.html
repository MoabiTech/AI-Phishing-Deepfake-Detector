🔐 Client-side encryption
How E2EE Works (Technical Details)
  • Key Generation: RSA-OAEP-2048 key pair generated in the browser session
  • Key Exchange: Public keys are relayed by the server; private keys stay in browser memory
  • Message and File Encryption: AES-256-GCM with a fresh key and 96-bit IV per transfer
  • Key Wrapping: RSA-OAEP with SHA-256 wraps the AES key for the recipient
  • Integrity: GCM authentication tags reject tampered ciphertext
  • Limitations: The demo does not authenticate public keys; a malicious server could substitute keys. Do not use for sensitive real-world communication.
